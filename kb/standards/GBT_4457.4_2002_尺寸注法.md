# 尺寸标注基本规则（§4.1）

机件的真实大小应以图样上所注的尺寸数值为依据，与图形的大小及绘图的准确度无关。

## 基本要求
- 图样中（包括技术要求和其他说明）的尺寸，以 mm 为单位时，不需标注计量单位的代号或名称。
- 如采用其他单位，则必须注明相应的计量单位代号或名称。
- 图样中所标注的尺寸，为该图样所示机件的最后完工尺寸，否则应另加说明。

# 尺寸界线（§4.2）

尺寸界线用细实线绘制，并应由图形的轮廓线、轴线或对称中心线处引出。

## 规则
- 尺寸界线一般应与尺寸线垂直，并超出尺寸线终端 2~3 mm。
- 必要时允许倾斜，但两尺寸界线仍应相互平行。
- 图形的轮廓线、轴线或中心线也可作为尺寸界线使用。

# 尺寸线（§4.3）

尺寸线用细实线绘制，其终端可以采用箭头或斜线两种形式。

## 规则
- 尺寸线不能用其他图线代替，一般也不得与其他图线重合或画在其延长线上。
- 标注线性尺寸时，尺寸线必须与所标注的线段平行。
- 相互平行的尺寸线，小尺寸在内、大尺寸在外，依次排列。

## 终端形式表

| 形式 | 适用场景 | 备注 |
|------|----------|------|
| 箭头 | 各类图样 | 推荐，机械制图默认 |
| 斜线 | 建筑、结构图 | 终端为 45° 斜细实线 |

# 尺寸数字（§4.4）

线性尺寸的数字一般应注写在尺寸线的上方，也允许注写在尺寸线的中断处。

## 方向规则
- 水平方向尺寸数字字头朝上。
- 垂直方向尺寸数字字头朝左。
- 倾斜方向尺寸数字字头有朝上的趋势。
- 尽量避免在图示 30° 范围内标注尺寸；如无法避免，应按引出标注形式标注。

# 直径标注（§4.5）

标注整圆或大于半圆的圆弧时，尺寸数字前加注符号 "φ"。

## 规则
- 直径尺寸线应通过圆心，两端用箭头指向圆弧。
- 当圆的直径较小时，允许将尺寸线画在圆外并指向圆心方向。
- 标注球面直径时，应在 "φ" 前再加 "S"。

# 半径标注（§4.6）

标注小于或等于半圆的圆弧时，尺寸数字前加注符号 "R"。

## 规则
- 半径尺寸线一端从圆心开始，另一端用箭头指向圆弧。
- 半径尺寸必须标注在反映圆弧实形的投影图上。
- 当圆弧半径过大或在图纸范围内无法标出圆心位置时，可采用折弯标注。

# 角度标注（§4.7）

标注角度的尺寸界线应沿径向引出，尺寸线应画成圆弧，圆心为该角的顶点。

## 规则
- 角度数字一律写成水平方向，一般注写在尺寸线的中断处。
- 必要时也可按引出标注形式标注在尺寸线外侧。
- 角度单位为度（°）、分（′）、秒（″）。

# 倒角标注（§4.8）

45° 倒角标注形式为 "C 倒角宽度"，如 C2 表示倒角宽度为 2 mm 的 45° 倒角。

## 规则
- 45° 倒角可在尺寸数字前加注 "C"。
- 非 45° 倒角需分别标注倒角宽度和角度。
- 倒角尺寸应直接注在倒角的投影面上。
