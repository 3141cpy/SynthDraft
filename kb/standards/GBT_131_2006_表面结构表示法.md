# 表面结构参数代号（§3.1）

表面结构参数代号由字母与数字组成，用于标注表面粗糙度、波纹度等几何特性。

## 参数代号说明
- Ra：算术平均偏差（轮廓算术平均偏差）。
- Rz：轮廓最大高度（5 个取样长度内的最大峰谷高度平均值）。
- Rq：轮廓均方根偏差。
- Rp：轮廓最大峰高。
- Rv：轮廓最大谷深。

## 取样长度
Ra 与 Rz 是最常用的表面粗糙度评定参数，取样长度与评定长度按 GB/T 10610 选取。

# 表面结构图形符号（§4.1）

表面结构要求由图形符号与参数代号、数值等组成。

## 符号类型

| 符号 | 含义 | 说明 |
|------|------|------|
| √ | 基本图形符号 | 仅用于简化标注，未指定工艺方法 |
| √（带横线） | 扩展图形符号 | 用去除材料的方法获得表面 |
| √（带圆圈） | 完整图形符号 | 用不去除材料的方法获得表面 |

## 完整符号构成
完整符号由基本符号 + 水平横线（传输带/参数代号/数值/补充要求）组成。

# 表面结构代号的标注位置（§4.2）

表面结构要求的完整代号由图形符号及 a、b、c、d、e 等位置组成。

## 位置说明表

| 位置 | 内容 |
|------|------|
| a | 传输带 / 取样长度（在上）+ 参数代号 + 数值 |
| b | 第二个表面结构要求（如需多个参数） |
| c | 加工方法、表面处理、涂层等 |
| d | 表面纹理方向符号 |
| e | 加工余量（mm） |

## 标注规则
- 表面结构代号应标注在轮廓线、尺寸界线或其延长线上。
- 代号的尖端必须从材料外指向表面。

# 表面纹理方向（§6.1）

表面纹理方向由加工方法决定，用纹理方向符号在代号位置 d 标注。

## 纹理方向符号表

| 符号 | 含义 | 说明 |
|------|------|------|
| = | 纹理平行于标注代号所在投影面 | 如纵向车削 |
| ⊥ | 纹理垂直于标注代号所在投影面 | 如端面车削 |
| × | 纹理呈两相交方向 | 如交叉磨削 |
| M | 纹理呈多方向 | 如研磨、珩磨 |
| C | 纹理呈近似同心圆 | 如端面车削中心 |
| R | 纹理呈近似放射形 | |

# 表面结构简化标注（§7.1）

当工件的多数表面具有相同的表面结构要求时，可使用简化标注。

## 简化方法
- 在图样的标题栏附近标注一个完整代号，并在其后加注括号内的基本符号 "（√）"。
- 仅在少数不同要求的表面上单独标注表面结构代号。
- 不同要求的表面也可采用 "（Ra3.2）" 等括号形式表示。

## 规则
- 简化标注必须明确指出哪些表面使用统一要求，避免歧义。
- 单独标注的代号优先级高于简化标注。
